# 台湾旅行 2026（公開用スナップショット）

このリポジトリは、Museスペース「台湾旅行 2026」の**公開用スナップショット**です。

## 正本について

- 正本は Muse スペース「台湾旅行 2026」側にあります。このリポジトリの `index.html` は、公開時点の内容を切り取った静的なコピーです。
- 旅行の内容（予約・日程・持ち物など）を変更したときは、Muse スペース側を更新したうえで、このリポジトリの `index.html` にも同じ内容を反映して push してください。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 公開ページ本体（自己完結・外部リソースなし） |
| `netlify.toml` | Netlify の公開設定（publish = "."、ビルドコマンドなし） |
| `README.md` | このファイル |

## デプロイ

Netlify でこのリポジトリを接続（Import）すれば、push のたびに自動でデプロイされます。ビルドコマンドは不要で、リポジトリ直下がそのまま公開されます。
